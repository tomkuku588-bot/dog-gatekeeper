Dog Gatekeeper Privacy Policy

最后更新：2026-06-01

语言

我们保存什么

狗狗守门员只在你的浏览器本机保存扩展设置、目标站点列表、按域名记录的使用秒数、更新时间、今日休息次数、计划休息秒数和完成休息任务次数。

这些数据用于提供目标站点计时、提前提醒、全屏休息遮罩、休息任务、暂停、清空计时和今日统计。

我们不保存什么

扩展不会保存或上传网页正文、搜索内容、账号密码、表单内容、聊天内容、精确浏览历史、个人身份信息、付款信息或位置数据。

数据是否离开本机

不会。设置、计时和统计都保存在 chrome.storage.local。扩展业务代码不发起远程网络请求，也不使用广告、统计 SDK 或第三方追踪服务。

权限说明

  • storage：保存本地设置、计时和今日统计。
  • 网页内容脚本：识别当前页面域名，只在目标站点本地计时，并显示提醒和休息遮罩。扩展不会把页面内容发送到任何服务器。

数据共享

我们不会出售、出租、传输或共享用户数据给第三方。我们不会使用用户数据投放个性化广告，也不会让人工读取用户数据。

用户控制

你可以在扩展弹窗中修改目标站点、清空当前站点计时、暂停守门或关闭扩展。卸载扩展会删除 Chrome 为该扩展保存的本地数据。

狗狗守門員只會在你的瀏覽器本機保存擴充功能設定、目標網站清單、按網域記錄的使用秒數、更新時間、今日休息次數、計畫休息秒數和完成休息任務次數。

我們不保存什麼

擴充功能不會保存或上傳網頁正文、搜尋內容、帳號密碼、表單內容、聊天內容、精確瀏覽紀錄、個人身份資訊、付款資訊或位置資料。

資料是否離開本機

不會。設定、計時和統計都保存在 chrome.storage.local。擴充功能的業務程式碼不會發起遠端網路請求，也不使用廣告、統計 SDK 或第三方追蹤服務。

權限說明

  • storage：保存本地設定、計時和今日統計。
  • 網頁內容腳本：識別目前頁面的網域，只在目標網站本地計時，並顯示提醒和休息遮罩。擴充功能不會把頁面內容傳送到任何伺服器。

資料共享

我們不會出售、出租、傳輸或共享使用者資料給第三方。我們不會使用使用者資料投放個人化廣告，也不會讓人工讀取使用者資料。

使用者控制

你可以在擴充功能彈窗中修改目標網站、清空目前網站計時、暫停守門或關閉擴充功能。解除安裝擴充功能會刪除 Chrome 為該擴充功能保存的本地資料。

What We Store

Dog Gatekeeper stores only local extension settings, the target domain list, per-domain usage seconds, update timestamps, today's break count, planned break seconds, and completed break task count in your browser.

This data is used to provide target-site timing, early warnings, the full-screen break overlay, break tasks, pausing, clearing timers, and daily statistics.

What We Do Not Store

The extension does not store or upload page content, search content, passwords, form values, chat content, precise browsing history, personally identifiable information, payment information, or location data.

Does Data Leave Your Device?

No. Settings, timers, and statistics are stored in chrome.storage.local. The extension's runtime code does not make remote network requests and does not use ads, analytics SDKs, or third-party tracking services.

Permission Explanation

  • storage: saves local settings, timers, and daily statistics.
  • Content scripts on web pages: detect the current page hostname, count time locally only on target sites, and display reminders and the break overlay. The extension does not send page content to any server.

Data Sharing

We do not sell, rent, transfer, or share user data with third parties. We do not use user data for personalized advertising, and no human reads user data.

User Control

You can edit target sites, clear the current site's timer, pause the guard, or disable the extension from the popup. Uninstalling the extension deletes the local data Chrome stores for this extension.

保存する情報

Dog Gatekeeper は、拡張機能の設定、対象ドメイン一覧、ドメイン別の使用秒数、更新時刻、今日の休憩回数、予定休憩秒数、完了した休憩タスク数だけをブラウザ内に保存します。

これらの情報は、対象サイトの計測、事前通知、全画面の休憩オーバーレイ、休憩タスク、一時停止、タイマーのリセット、今日の統計を提供するために使われます。

保存しない情報

この拡張機能は、ページ本文、検索内容、パスワード、フォーム入力、チャット内容、詳細な閲覧履歴、個人識別情報、支払い情報、位置情報を保存またはアップロードしません。

データは端末外へ送信されますか

いいえ。設定、タイマー、統計は chrome.storage.local に保存されます。拡張機能の実行コードはリモートのネットワークリクエストを行わず、広告、分析 SDK、第三者トラッキングサービスも使用しません。

権限の説明

  • storage：ローカル設定、タイマー、今日の統計を保存します。
  • Web ページ上のコンテンツスクリプト：現在のページのホスト名を識別し、対象サイトでのみローカルに時間を計測し、通知と休憩オーバーレイを表示します。ページ内容をサーバーへ送信することはありません。

データ共有

ユーザーデータを第三者へ販売、貸与、転送、共有することはありません。ユーザーデータをパーソナライズ広告に使用することも、人が読み取ることもありません。

ユーザーによる管理

ポップアップから対象サイトの変更、現在のサイトのタイマー削除、ガードの一時停止、拡張機能の無効化ができます。拡張機能をアンインストールすると、Chrome がこの拡張機能のために保存しているローカルデータは削除されます。
